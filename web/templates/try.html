The four steps

1 · Put a permission slip on file

Registry → Add permission slip → upload contract.pdf. Gemini fills in six fields and has to quote the sentence it took each one from; any field whose quote is not found on the page it claims is dropped rather than guessed. You confirm before it is saved, because a wrong slip quietly makes every later answer wrong.

Then do the other two, because they are the cases that catch people out. contract-expired.pdf looks like an ordinary live grant and lands in the registry marked expired — its term ran out on 1 September. contract-withholding.pdf hides a clause forbidding synthetic likeness inside a paragraph of things the producer may do; the reading records voice and archival reuse and refuses the likeness, which is the distinction the whole registry rests on.

{% if can_act %}Start here{% endif %}

2 · Sweep the web

Enforcement Sweep → Run sweep now. Gemini writes search phrases in five languages, Parallel runs them, and each page that comes back is fetched and read. Real third-party results are counted and withheld — we will not publish an authorisation verdict naming a real company from a public demo — so the finding you see recorded is a page we host ourselves at /demo/listing. Open it: the verdict quotes that page word for word.

{% if can_act %}Go to the sweep{% endif %}

3 · Open the case file

On any finding, Open the case file. It draws together what was found, the clause it breaches, the copy of the page we keep, and a draft notice. There is no send button and there never will be — the product has no way to send anything.

4 · Check your own footage

Clearance Check → upload voice-clip.wav as a synthetic voice for US: it clears. Submit the same file for BR: blocked, because the grant is scoped to the US and Canada. Then try face-still.jpg as a synthetic face: blocked, because clause 10(a) withholds visual likeness.

Same rule engine as step 2. A studio gets exactly the answer about its own footage that a stranger would get about theirs, which is the whole point of building one engine instead of two.
